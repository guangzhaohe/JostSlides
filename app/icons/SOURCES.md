# JostSlides icon

`jostslides.png` was generated for this repository with the built-in OpenAI image generation tool on 2026-10-02. It uses the presentation examples' black and pastel palette and simple slide-card primitives. The PNG retains its transparent background and is shared by the README heading and the slideshow favicon. The build embeds it into every generated HTML page so portable decks need no separate icon file.

Use case: `logo-brand`.

Initial prompt:

> Create a clean square logo icon for JostSlides, a presentation framework. Two slightly overlapping rounded black slide cards, with one large mint circle and one small gold triangle on the front card and a subtle pastel pink edge on the rear card. Bold simple geometric primitives, flat colors, crisp silhouette, readable at 40 pixels. Centered with generous transparent padding. No text, no letters, no gradients, no shadows, no mockup. Transparent background.

Final framing edit prompt:

> Edit this JostSlides logo only to tighten the framing for a browser favicon: make the existing stacked slide cards fill 90% of the square canvas, leaving only a small transparent margin. Preserve the same shapes, proportions, colors, black front card, mint circle, gold triangle, and pink rear edge. Keep true transparent background. No text or extra elements.
