# A tiny talk

A six-slide starter with the same black/Jost style as the feature showcase. It contains no media dependencies: large text, native panels, a literal Python-to-slide example, automatic transitions, three reveal steps, and a clickable discussion question.

```bash
python slides.py check --deck 2026-10-02
python slides.py serve --deck 2026-10-02
python slides.py export --deck 2026-10-02
```

Use the header deck picker to switch to the complete [interactive showcase](../2026-09-24/README.md). Notes remain separate because each deck has its own stable ID.

Created with `python slides.py new 2026-10-02 --title "A tiny talk"`. Adapt `deck.py` and keep its deck/slide IDs stable. There are no external numerical claims or images; provenance is in [references/SOURCES.md](references/SOURCES.md).
